# Jet Set

A fast card game for 2 to 4 players: deals, rent and dirty tricks. Collect three full sets of destinations to win.

**Play:** https://claudioelbikai-tech.github.io/jetset/

- **Play on this phone**: pass the phone between turns.
- **Play online**: each player on their own phone. Open a table and send the link; up to 4 players can join before the deal.
- **Practice**: you against 1 to 3 computer players.

House rule: full sets are safe from rent and debts. You never pay with a full set; only a Deal Breaker can take one.

Fair deal: every starting hand has 1 money card, 2 properties and 2 action or rent cards, about the same total value, with the strongest cards spread out. Everything drawn after that is random.

The whole game is one page, `index.html`. Online tables sync through a public MQTT relay. The table code in the link is the only key, so share it only with the people you play with.
